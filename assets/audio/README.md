## 📝 File Naming Convention

Audio files **MUST** be named using **kebab-case** (lowercase with hyphens) based on the devotion title.

### Examples:

| Devotion Title | Audio Filename |
|---------------|----------------|
| "Finding Peace in the Storm" | `finding-peace-in-the-storm.mp3` |
| "Strength for Today" | `strength-for-today.mp3` |
| "Love in Action" | `love-in-action.mp3` |
| "God's Provision" | `gods-provision.mp3` |

### Naming Rules:
- Convert to lowercase
- Replace spaces with hyphens (`-`)
- Remove special characters (apostrophes, commas, periods, etc.)
- Remove multiple consecutive hyphens

## 🔧 How the System Works

### 1. Automatic Generation
When you run `node scripts/generate-audio-helper.js`, it:
- ✅ Reads all 365 devotion titles from `constants/devotionals.ts`
- ✅ Converts each title to kebab-case
- ✅ Generates `utils/audioHelper.ts` with all 365 audio mappings
- ✅ Creates `audio-file-checklist.txt` with all filenames

### 2. Your Workflow
```bash
# Step 1: Generate audio mappings (already done for you!)
node scripts/generate-audio-helper.js

# Step 2: Add your MP3 files to this folder
# - Use the names from audio-file-checklist.txt
# - Files will automatically be detected

# Step 3: Rebuild your app
npm run ios  # or npm run android
```

### 3. Runtime Behavior
- ✅ Each day, the app loads the devotion for that day of the year
- ✅ The audio helper automatically finds the matching audio file
- ✅ If the file exists → music player appears
- ✅ If the file doesn't exist → music player is hidden (no errors!)

## 📊 File Requirements

### Recommended Specs:
- **Format**: MP3
- **Bitrate**: 128-192 kbps (good balance of quality and size)
- **Sample Rate**: 44.1 kHz
- **Max Size**: 5-10 MB per file (for reasonable app size)
- **Total**: 365 files × ~5 MB = ~1.8 GB

### Supported Formats:
- `.mp3` (recommended)
- `.m4a`
- `.wav` (not recommended - very large)

## 📞 Troubleshooting

**Music player not showing?**
- ✅ Check the console logs for: `ℹ️  No audio file registered for: [filename].mp3`
- ✅ Verify the MP3 file exists in `/assets/audio/`
- ✅ Verify the filename matches the checklist exactly (case-sensitive!)
- ✅ Rebuild the app after adding new files

**Wrong audio playing?**
- ✅ Verify the day-of-year calculation is correct
- ✅ Check `audio-file-checklist.txt` to see which file should play for each day
- ✅ Ensure devotion titles haven't changed

**App size too large?**
- ✅ Reduce MP3 bitrate to 128 kbps
- ✅ Shorten audio length if possible
- ✅ Consider hosting audio files remotely (future enhancement)
