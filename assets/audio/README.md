# Audio Assets

Place your devotional music/audio files here.

## File Naming Convention

Use one of these formats:

### Option 1: By Devotion Title (Recommended)
```
finding-peace-in-the-storm.mp3
strength-for-today.mp3
love-in-action.mp3
```

### Option 2: By Day Number
```
devotion-001.mp3
devotion-002.mp3
devotion-003.mp3
...
devotion-365.mp3
```

### Option 3: Generic Sample
```
sample-devotion.mp3  (placeholder for testing)
```

## Supported Formats

- MP3 (recommended)
- M4A
- WAV
- AAC

## File Size Recommendations

- **Optimal**: 2-5 MB per file (3-5 minutes at 128-192 kbps)
- **Maximum**: 10 MB per file

## How to Add Files

1. Copy your audio file to this folder:
   ```
   /Users/gabbydev5/Desktop/daily-bread-mob/assets/audio/
   ```

2. Name it according to the convention above

3. The app will automatically pick it up!

## Current Structure

```
assets/
└── audio/
    ├── README.md (this file)
    └── [your-audio-files-here].mp3
```

## Notes

- Files are bundled with the app (included in app size)
- Users can play offline
- Audio plays through device speakers/headphones
- Supports background playback
