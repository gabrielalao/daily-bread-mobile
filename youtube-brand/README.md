# CDB Therapy — YouTube Brand Assets

Use these files when setting up your YouTube channel.

## Profile picture (channel icon)

| File | Size | Best for |
|------|------|----------|
| `youtube-profile-800x800.png` | 800×800 | **Recommended** — YouTube upload |
| `youtube-profile-512x512.png` | 512×512 | Smaller preview / social |
| `youtube-profile-with-name-800x800.png` | 800×800 | Icon + “CDB Therapy” text |
| `cdb-logo-original.png` | App source | Same as app icon (no resize) |

YouTube displays profile pictures as a **circle** — keep important content centered.

## Channel banner

| File | Size | Upload? |
|------|------|---------|
| **`youtube-banner-2048x1152.png`** | **2048×1152** (~50 KB) | **Yes — recommended** (YouTube min + under 6 MB) |
| `youtube-banner-2560x1440.png` | 2560×1440 | Also valid (larger option) |
| `youtube-banner-SAFE-ZONE-GUIDE.png` | 2560×1440 | Reference only (safe area overlay) |

### YouTube banner requirements

| Requirement | Value |
|-------------|--------|
| **Minimum size** | **2048 × 1152 px** (or 2560 × 1440) |
| **Max file size** | **6 MB or less** |
| **Safe area (phones)** | Center **~1236 × 338** on 2048×1152 (logo + text stay here) |

**YouTube Studio:** Customization → Branding → Banner image → upload **`youtube-banner-2048x1152.png`**

## Brand colors (from the app)

- Background: `#000000`
- Primary teal: `#2A9D8F`
- Accent: `#1DB9A8`

## Upload in YouTube Studio

1. [YouTube Studio](https://studio.youtube.com) → **Customization** → **Branding**
2. **Profile picture** → upload `youtube-profile-800x800.png` (or the with-name version)
3. **Banner image** → upload `youtube-banner-2560x1440.png`
